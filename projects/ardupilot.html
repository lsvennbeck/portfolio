Ardupilot


Role: UX, visual design
Team: Lars Svennbeck

I have redesigned Ardupilot Mission planner, which is an open-source drone flight and mission planning software. To enhance the user experience I've made the following improvements:

Actions and data now displays simultaneously, no need to switch between windows during flight.

Action buttons are now logically grouped, providing a more intuitive layout.

Video stream visibility has been improved by removing overlaid flight display information.
